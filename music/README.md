# Game music

Songs in this folder play in the game for everyone.

1. Copy your MP3 / M4A / MP4 / OGG / WAV files into this folder.
2. List their file names in `playlist.json`, in the order you want:

```json
{ "songs": ["night drive.mp3", "harbour lights.mp4"] }
```

3. Commit and push. The game picks them up on its next launch.

Players can also add their own songs from the game's menu (Music → Add songs / Add folder); those stay in their browser only. Only add music you have the rights to share.
